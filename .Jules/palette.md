## 2025-05-15 - Timezone Converter Swap Button & Accessibility Baseline
**Learning:** Adding a "Swap" button between bidirectional inputs (like "From" and "To" selectors) significantly reduces user friction. Accessibility for icon-only buttons is a common oversight in fast-paced projects.
**Action:** Always check for bidirectional workflows that can benefit from a swap action. Ensure all `<button>` elements have either text content or an `aria-label`. Use `for` attributes on `<label>` to link with input `id`.

## 2026-07-19 - Seamless Cross-Page Section Scrolling and Anchor Accessibility
**Learning:** Hardcoded page switching during anchor scrolling breaks generic utility links. Dynamically resolving the parent page of an element via `.closest('.page')` before scrolling provides robust navigation. Additionally, standard page transition scrolls can fight section scroll-into-view animations; passing a `skipScroll` parameter prevents jarring double-scroll jumps. Lastly, anchor elements without `href` attributes cannot be focused via keyboard; utilizing `href="javascript:void(0)"` is a powerful, zero-CSS way to restore native keyboard focusability.
**Action:** Implement dynamic parent-page detection for all anchor scroll utilities, bypass default scroll-to-top behaviors during targeted scroll transitions, and ensure pseudo-link anchors have `href="javascript:void(0)"` for full a11y compliance.
